# 宝塚漢字学習アプリ ✨

宝塚歌劇団のスター（現役＋歴代人気スター）の美しい芸名で漢字を学習するWebアプリケーションです。

## 📖 概要

- 宝塚歌劇団の現役スターと歴代人気スターの芸名を使った漢字学習アプリ
- 対象レベル：小学2年生（漢字検定10級・9級）
- 組別テーマカラーで華やかなUI
- Google Custom Search API連携で実際の劇団員写真表示に対応
- 正解履歴をポートフォリオとして保存・管理

## 🚀 起動方法

### 1. ローカルHTTPサーバーで起動（推奨）

```bash
# プロジェクトディレクトリに移動
cd /home/user/takarazuka-revue

# Python 3でHTTPサーバーを起動
python3 -m http.server 8080

# ブラウザでアクセス
# http://localhost:8080/index.html
```

### 2. 直接HTMLファイルを開く

```bash
# ブラウザで直接開く（一部機能に制限がある場合があります）
open index.html
```

## 🎯 主な機能

1. **漢字クイズ**: 宝塚スターの芸名から漢字の読み方を学習
2. **組別テーマ**: 月組・花組・雪組・星組・宙組の5つの組に対応
3. **写真表示**: Google Custom Search API連携で実際の写真表示（要設定）
4. **ポートフォリオ**: 正解した問題を記録・エクスポート
5. **進捗管理**: 学習進捗をリアルタイムで表示

## ⚙️ Google API設定（オプション）

実際の劇団員写真を表示するには、Google Custom Search APIの設定が必要です。

詳細は [GOOGLE_API_SETUP.md](./GOOGLE_API_SETUP.md) を参照してください。

## 📝 使い方

1. アプリを起動し、「スタート ✨」ボタンをクリック
2. 表示される劇団員の芸名から漢字の読み方を選択
3. 正解すると劇団員のプロフィールが表示されます
4. 全60問にチャレンジしましょう！

## 🌟 組について

- 🌙 **月組** (tsuki) - ダークブルー
- 🌸 **花組** (hana) - レッド
- ❄️ **雪組** (yuki) - ホワイト
- ⭐ **星組** (hoshi) - ティール
- 🌌 **宙組** (sora) - ブルー
